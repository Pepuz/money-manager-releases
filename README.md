# Money Manager — APK per Android

App Android per tenere i conti personali: movimenti, conti e carte,
ricorrenti, budget e statistiche. È un progetto personale in sviluppo. Questo
repository contiene solo i file di installazione (APK), non il codice.

## Installazione e aggiornamenti

L'app si installa e si aggiorna con
[Obtainium](https://github.com/ImranR98/Obtainium), che legge le release di
questo repository.

1. Installa Obtainium dalla sua pagina ufficiale.
2. In Obtainium aggiungi un'app con questo indirizzo:
   `https://github.com/Pepuz/money-manager-releases`
3. Installala. La prima volta Android chiede di consentire a Obtainium
   l'installazione di app: conferma.

Obtainium avvisa quando esce una versione nuova.

Ogni versione è firmata con lo stesso certificato, e Android rifiuta un
aggiornamento firmato con un altro. Impronta SHA-256 del certificato:

```
727969abf3e9bf90ae2df2317e9dd28b2a02dfd846ac8b4a6d59aa5118111392
```

## Prima di aggiornare

Conviene esportare un backup: nell'app, ingranaggio in alto a destra →
Impostazioni → "Esporta backup".

## I tuoi dati

- I dati restano sul telefono: l'app non ha account e non li invia a nessun
  server. Chi pubblica l'app non riceve nulla.
- Il collegamento a un PC, se lo attivi, invia i dati solo al PC abbinato.
- Android può includere i dati nel backup Google del tuo account, se è attivo.

## Avvertenze

- L'app è fornita così com'è, senza garanzie, nei limiti consentiti dalla
  legge.
- Non è una consulenza finanziaria.
- Non è collegata ad altre app con nomi simili.
